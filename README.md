## 🛠 Tech Stack & Tools

This project leverages a suite of professional tools for circuit design, mobile interface development, and AI integration.

### 🔌 Hardware Design & Simulation
* **[Circuito.io](https://www.circuito.io/)**: Used for instant circuit architecture and automated wiring diagrams. It ensures component compatibility and provides a solid base for the hardware setup.
* **[Cirkit Designer](https://app.cirkitdesigner.com/)**: Utilized for creating high-quality, professional circuit schematics and documenting the physical layout of the project.

### 📱 Control & User Interface (GUI)
* **[RemoteXY](https://remotexy.com/)**: The primary platform for mobile graphical interface design. It enables seamless smartphone control over Arduino/ESP32 via Bluetooth or WiFi with minimal overhead.
* **[MIT App Inventor](https://ai2.appinventor.mit.edu/)**: Used to develop a customized Android application, allowing for tailored logic and enhanced interaction between the mobile device and the IoT system.

### 🧠 AI & Advanced Processing
* **[UBTECH AI Box](http://docs.ubtrobot.com/aibox/#/en-us/README.md)**: Integrated for adding AI capabilities. This platform provides the documentation and tools necessary for implementing intelligent automation and pattern recognition.

### 📖 Academic Framework & Protocols
* **[CS PUB IoT Labs](https://ocw.cs.pub.ro/courses/iot/labs/02)**: Followed as a technical reference for sensor interfacing, data acquisition protocols, and low-level communication strategies.
