🛠 Tech Stack & Tools
This project leverages a suite of professional tools for circuit design, mobile interface development, and AI integration.

🔌 Hardware Design & Simulation
Circuito.io: Used for instant circuit architecture and automated wiring diagrams. It ensures component compatibility and provides a solid base for the hardware setup.

Cirkit Designer: Utilized for creating high-quality, professional circuit schematics and documenting the physical layout of the project.

📱 Control & User Interface (GUI)
RemoteXY: The primary platform for mobile graphical interface design. It enables seamless smartphone control over Arduino/ESP32 via Bluetooth or WiFi with minimal overhead.

MIT App Inventor: Used to develop a customized Android application, allowing for tailored logic and enhanced interaction between the mobile device and the IoT system.

🧠 AI & Advanced Processing
UBTECH AI Box: Integrated for adding AI capabilities. This platform provides the documentation and tools necessary for implementing intelligent automation and pattern recognition.

📖 Academic Framework & Protocols
CS PUB IoT Labs: Followed as a technical reference for sensor interfacing, data acquisition protocols, and low-level communication strategies.


الأداة,التصنيف,الوظيفة الأساسية في المشروع
Circuito.io,الهاردوير,اختيار القطع الإلكترونية وتوليد مخطط التوصيل الآلي.
Cirkit Designer,الهاردوير,رسم وتوثيق المخطط النهائي للدائرة بشكل احترافي.
RemoteXY,التحكم,بناء واجهة أزرار ومؤشرات للتحكم عبر الموبايل.
MIT App Inventor,التطبيقات,برمجة تطبيق أندرويد مخصص للتعامل مع بيانات النظام.
AI Box (UBTECH),الذكاء الاصطناعي,دمج قدرات المعالجة الذكية والتعرف على الأنماط.
CS PUB Lab 02,البرمجيات,مرجع برمجي لربط الحساسات ومعالجة بروتوكولات البيانات.
